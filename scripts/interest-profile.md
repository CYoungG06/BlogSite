# 论文速递兴趣画像

读者是 LLM 方向的研究者与工程师,日常做后训练 / Agent 相关研究与工程。
本文件是每日论文 AI 评分的裁判依据:score 打 0–10 的相关分,deepDive 标出值得深度解读的候选。
画像会持续维护——误判的论文按类追加到对应清单。

## 高分方向(关注)

- **LLM 架构与预训练**:新架构、MoE、注意力变体(线性/稀疏/混合)、长上下文、训练稳定性、scaling law、优化器
- **后训练**:RLHF / GRPO / DPO / RLVR、蒸馏(尤其 on-policy distillation)、对齐、推理与长思维链、test-time scaling、自我改进 / 自进化
- **Agent**:工具调用、规划、harness / scaffold、多智能体、Agentic RL、环境与本任务合成、记忆、自博弈
- **代码智能**:代码模型、编程智能体、SWE 类任务、kernel / 编译优化
- **多模态大模型(理解侧)**:MLLM / VLM 的架构、训练与推理,视觉编码器与语言模型的结合
- **评测与方法学**:benchmark 设计、LLM-as-judge、可验证奖励、评估可靠性
- **系统与效率**:高效训练 / 推理、量化、投机解码、KV cache、并行策略、推理框架
- **AI for Research**:科研智能体、自动发现、文献理解

## 低分方向(不关注)

- 音频 / 视频 / 图像生成,视觉生成统一建模
- 视觉重建(3D / NeRF / Gaussian Splatting)
- 扩散模型(包括扩散语言模型,一刀切)
- 偏物理 / 硬件 / 光子 / 量子
- 生物医药 / 医疗影像 / 蛋白质结构 / 生物信息学
- 与 LLM 无关的纯理论、经典数值 / 统计方法
- 机器人与具身智能(一刀切):VLA(Vision-Language-Action)、机器人基础模型、操作 / 导航 / 控制、经典控制 RL——即便用了 LLM/VLM 组件也归低分
- 语音识别 / 口语评测 / TTS 等语音应用
- 能源 / 交通 / 农业 / 气象 / 教育等垂直行业应用
- 纯硬件电路、EDA、嵌入式、网络协议等传统 CS 工程题
- 偏门交叉领域(与上述高分方向无交集时)

## 打分手则

- **9–10**:直接命中高分方向且有分量——新架构 / 新范式 / 旗舰模型技术报告 / 重要系统性工作
- **7–8**:高分方向内的扎实工作,方法清晰、结果可信
- **5–6**:方向擦边、增量改进,或选题有趣但分量有限
- **3–4**:偏离关注方向,但沾一点边(如涉及 LLM 的垂直应用)
- **0–2**:完全落在低分方向
- 拿不准时给 5(边界从宽,交给展示层过滤)

## deepDive 手则(深度解读候选)

同时满足才标 true:

- score ≥ 8
- 有深度可拆解:方法新颖、系统性强、实验数据丰富,或旗舰 / 综述级技术报告
- 纯 benchmark 发布、小改进、短 workshop 论文不标
