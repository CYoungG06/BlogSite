# 具身智能栏目兴趣画像

读者做 LLM 后训练 / Agent 研究,看具身方向是为了跟踪「大模型与智能体的方法如何进入物理世界」,
不做机器人本体与控制。本文件只用于速递里「具身智能」栏目的打分(主栏目见 interest-profile.md):
主分类为 cs.RO 的论文,以及被裁判标为具身主题的其他论文,按这份画像评分。
画像会持续维护——误判的论文按类追加到对应清单。

## 高分方向(关注)

- **智能体式机器人**:LLM / VLM 智能体直接当机器人策略或写代码控制机器人(code-as-policy)、robot-use agent、
  机器人的 harness / scaffold、具身智能体的记忆与规划、自我改进 / 自进化、具身智能体安全
- **VLA 的训练与后训练**:Vision-Language-Action 模型的架构与预训练配方、RL 微调 / 在线自适应、蒸馏、
  推理与思维链、动作表示与解码、旗舰 VLA / 具身基础模型的技术报告
- **世界模型与世界-动作模型(WAM)**:机制有新意或规模上有突破的工作、想象规划、世界模型用于策略改进
- **具身评测与方法学**:评估通用大模型具身能力的基准、真机 / 仿真评估的可靠性、挑战赛的系统性方案

## 擦边方向(至多 5–6 分)

- 数据与规模化:人类 / 第一视角视频到机器人、遥操作、数据引擎与合成、跨本体迁移、车队 / 集体学习
  ——除非同时是上面某个高分方向的核心贡献

## 低分方向(不关注)

- 底层控制与本体:人形全身控制、步态与运动、灵巧手与触觉的低层策略、纯模仿学习小改进
- 传统机器人学:MPC / 最优控制、SLAM / 里程计 / 建图、运动规划、标定、状态估计
- 感知专项:LiDAR / 雷达 / 深度估计 / 3D 重建
- 自动驾驶(一刀切)
- 工业 / 医疗 / 建筑 / 农业等垂直机器人应用,硬件与机构设计

## 打分手则

- **9–10**:直接命中高分方向且有分量——新范式 / 旗舰模型或系统 / 重要的系统性工作
- **7–8**:高分方向内的扎实工作,方法清晰、结果可信
- **5–6**:擦边方向,或高分方向内的增量改进(如又一个 VLA / WAM 变体但机制新意有限)
- **3–4**:偏离关注方向但沾边(如用了 VLM 组件的底层控制)
- **0–2**:完全落在低分方向
- 拿不准时给 5

## deepDive 手则(深度解读候选)

同时满足才标 true:

- score ≥ 8
- 有深度可拆解:方法新颖、系统性强、实验数据丰富,或旗舰 / 综述级技术报告
- 纯 benchmark 发布、小改进、短 workshop 论文不标
