## 动机:好想法不是「缝」出来的

让 LLM 做科研构想(scientific ideation)——从研究背景出发提出新颖可行的方法——目前主流是**智能体式的外部脚手架**:多智能体辩论、迭代文献综述、模拟同行评审……把模型编排进复杂工作流里模拟人类研究过程。但我们观察到,这类方法产出的想法常常是**表面新颖的概念重组**:换个说法、做个关键词联想、把两个模块拼在一起,读起来流畅,却缺乏真正的技术深度和科学根基。

问题出在哪?脚手架终究是外部编排,模型本身并没有学会「为什么要做这个研究」。一个好想法的本质,是一条从**研究动机**到**可行方法**的完整逻辑链——而原生 LLM 恰恰缺少对动机的建模。

另一条路是用强化学习直接增强模型的内在推理能力。数学、工具调用这类任务上有确定性验证器,RL 已经很成功;但科学构想是**开放式任务,没有标准答案**,奖励从哪来?内在信号太松、模型打分太贵且容易被 reward hacking——这是横在 RL 面前的真问题。

## 方法:动机锚定推理 + 双粒度奖励

**把科学构想拆成两段条件推理。** 给定研究上下文 $x$(主题、背景、关键文献),MoRI 先提出**研究动机** $m \sim \pi_\phi(\cdot \mid x)$(发现的 gap、科学原理与高层方向);再以 $x \oplus m$ 为条件生成**推理轨迹** $z$ 与**方法论** $y$,即 $(z, y) \sim \pi_\theta(\cdot \mid x, m)$。推理轨迹是动机通向方法的逻辑桥——模型被迫做「有动机的解题」,而不是「看上下文续写」。推理时同样级联进行:先动机,后演绎。

**数据与冷启动。** 我们从 ICLR 2024–2025 录用论文中构建构想数据集:PDF 转 Markdown 后抽取标准化的上下文与动机,方法描述做**去符号化**以聚焦语义逻辑;论文里通常没有显式推理链,我们用**后验重构**合成 $z$——先让推理模型基于 $x$ 打草稿,再让另一个模型在 $x$ 与真实方法 $y^*$ 条件下改写对齐。SFT 冷启动教两个任务(动机生成、方法生成),4000 条做 SFT、2000 条留作 RL 提示,保证 RL 见到的是新上下文。

**双粒度复合奖励——这篇工作的核心。** 开放式任务没有验证器,我们设计了一对互补的代理奖励:微观上,好的推理应该**有解释力**(让真实方法里的复杂技术细节变得更可及);宏观上,好的推理应该**有建设性**(在语义空间里真正从问题走向答案)。

- **EAIG(熵感知信息增益,微观技术深度)**:方法里的 token 并不平等——功能短语谁都会写,真正的创新在高复杂度的技术术语上。我们用 SFT 模型的预测熵筛出真实方法中熵最高的 25% token 作为掩码 $M_t$,再计算逐点信息增益

$$g_t(z) = \log \pi_\theta(y^*_t \mid x, m, z, y^*_{<t}) - \log \pi_{\mathrm{SFT}}(y^*_t \mid x, m, y^*_{<t})$$

即「有了这段推理,难的技术细节变得多可及」,最终 $\Delta_{IG}(z)$ 是掩码位置上的平均增益。

- **CSG(对比语义增益,宏观逻辑方向)**:用嵌入模型分别算生成方法与真实方法的语义相似度 $S_{gen}$、输入与真实方法的基线相似度 $S_{base}$,取差 $\Delta_{sem} = S_{gen} - S_{base}$——增益为正才说明推理带来了**真实的语义推进**,而非复述问题。

- **防作弊正则**:长度锚定 $\alpha(z) = \min\!\big(1,\; 1 - \lambda\,\frac{L_{anchor} - |z|}{L_{anchor}}\big)$ 惩罚过短的推理(堵死「走捷径拿分」);格式门 $\mathbb{1}[\mathrm{valid}]$ 对空推理、过短、结构泄漏直接归零。总奖励:

$$R_{total} = \alpha(z) \cdot \mathbb{1}[\mathrm{valid}] \cdot \big(w_1\, f_{step}(\Delta_{IG}) + w_2\, f_{step}(\Delta_{sem})\big)$$

优化用 GRPO(token 级损失 + clip-higher),底座为 DeepSeek-R1-Distill-Qwen-14B。

## 实验结果

评测覆盖 **ICLR 域内测试集(85 篇)**与 **NeurIPS 域外测试集(67 篇)**,从新颖性(Nov)、技术严谨性(Rig)、可行性(Feas)三维度打分;评审采用检索增强的 LLM judge(Gemini-2.5-Pro),并与三位博士研究者的盲评对齐(Pearson $r = 0.715$,$p < 0.001$)。

- **整体第一**:MoRI 综合均分 **3.18**,较 Full-SFT 提升 **8.5%**,较智能体框架 AI-Scientist-V2(GPT-4o)提升 **22.3%**;对绝大多数基线的优势通过显著性检验($p < 0.001$, Cohen's $d > 0.8$)。
- **与 Claude-3.5-Sonnet 互补**:Sonnet 在新颖性上领先,但 MoRI 在技术严谨性(+2.9%)与可行性(**+10.3%**,3.11 vs 2.82)上反超,综合均分更高——商业模型倾向于提出「概念新奇但难以落地」的想法,而 MoRI 的想法既有创新性又方法论扎实。
- **域外泛化**:在未见过的 NeurIPS 测试集上保持 3.15,说明学到的是可迁移的推理模式,而非对特定会议的记忆。

**消融验证每个设计都成立**:动机条件化让两阶段 SFT(2.85)超过直接生成(2.75),RL 再拿 +0.30;奖励组合上,只用 EAIG 会崩盘(2.51,模型钻熵指标的空子)、只用 CSG 稳定但次优(3.05),**语义为主、细节为辅($w_s{=}0.7$, $w_e{=}0.3$)最优(3.15)**;熵掩码收紧到 top-25% 比 50% 再提 3.7%;去掉长度锚定则 CoT 迅速坍缩(3.09 → 2.89)。

## 亮点

- **问题形式化**:首次将科学构想建模为动机锚定的两阶段推理任务,让「从动机演绎方法」成为可学习、可优化的目标。
- **双粒度奖励框架**:EAIG 管微观技术深度、CSG 管宏观语义方向,为「无验证器的开放式任务如何做 RL」给出了一种可行答案,配合长度锚定与格式门有效防 reward hacking。
- **内化的科研推理行为**:定性分析显示 MoRI 学会了三种研究者式的推理模式——**目标分解与约束枚举**、**假设-批判-修正循环**、以及**反向质问范式**(先质疑主流方法的立论根基,找到文献缺失的角度)。模型是在推理,不是在套模板。

我们希望 MoRI 能成为研究者的「构思搭子」:在科研早期帮忙快速探索假设、识别空白、把动机落成方法,把人的精力还给实验与思考本身。
