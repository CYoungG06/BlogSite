### StateM：通过 Harness Scaling 在 Terminal-Bench 2.1 上达到 95.3% 原始准确率，或 15 美元的前沿级运行

### HarnessEval-W:将视觉世界评估智能体化
- HarnessEval-W: Agentifying the Evaluation of Visual Worlds
- 评分 7 · ▲ 115
- https://arxiv.org/abs/2608.16859 ｜ https://arxiv.org/pdf/2608.16859

世界模型评测通常只输出一个标量分数，缺少可核验的推理链，难以判断rollout中物理、因果与世界状态演变是否正确。HarnessEval-W 将 LLM 生态中的 harness 范式引入世界模型基准评测:由主智能体理解评估上下文、拆解评测问题，并生成配备专用上下文与诊断工具的子智能体分别推理，再将证据汇总为最终判定。该分层流程将每次评估变成透明的证据树，完整保留决策依据。在 18 个世界模型、330 个评估用例上，其判断与人类偏好高度一致，并提供细粒度的可验证诊断;完整流程已开源，支持社区扩展评估技能与用例。

### 大型发现模型：基于经验建模的模型驱动开放式搜索

- 评分 8 · ▲ 56 · 精读候选
- https://arxiv.org/abs/2608.15669 ｜ https://arxiv.org/pdf/2608.15669

### MOSS-VL 技术报告

- https://arxiv.org/abs/2608.15045 ｜ https://arxiv.org/pdf/2608.15045

### Ventor-QTest：威胁模型驱动的供应商托管 LLM API 验证
- Ventor-QTest: Threat-Model-Driven Verification of Vendor-Hosted LLM APIs
- 评分 7 · ▲ 12
- https://arxiv.org/abs/2608.16391 ｜ https://arxiv.org/pdf/2608.16391

第三方托管的开源权重 LLM 推理 API 质量难以审计。Ventor-QTest 将托管模型路由建模为随机过程，用重复请求重构输出分布并计算平均保真损失（AFL），再用长序列独立运行计算极端保真损失（EFL），全程无需目标 API 提供概率信息。在 logprob 可用的路由条件下，AFL 与 logprob 导出的 coarsened-KL 比较器呈强线性一致；七个路由快照的 20 次运行探针显示 EFL 存在路由差异，且 EFL 升高与 Terminal-Bench 通过率随任务暴露下降吻合，提示长程 agentic 任务对极端保真损失更敏感。开源实现已发布，适合作为调用第三方 API 时的质量审计与风险筛查工具。

### R^3-Bench: 共享预算下 LLM 在资源理性推理上的困难

### LLM 能否处理信念与事实取决于表述方式
- Whether LLMs Can Navigate Beliefs and Facts Depends on How You Phrase It
- 评分 7 · cs.CL
- https://arxiv.org/abs/2608.17809 ｜ https://arxiv.org/pdf/2608.17809
