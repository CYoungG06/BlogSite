- Agents That Edit Documents: Measuring Agentic PDF Forgery Against a Non-Agentic Control
- 评分 7 · cs.AI

### XYEval：智能体对糟糕建议说“是”
- XYEval: Agents say yes to bad advice
- 评分 8 · cs.CL
- https://arxiv.org/abs/2609.23939 ｜ https://arxiv.org/pdf/2609.23939

XY问题指用户只问自己设想的解决方案而非真实问题，这一沟通陷阱在agentic场景中缺少系统评估。XYEval是一个元评估框架，能把现有benchmark自动转成XY问题变体，检验智能体能否抵御看似合理却有误导性的用户建议并说明自身推理。在六个基准套件、五个模型上，XY变异使智能体性能大幅下降，相对跌幅最高达46.7%；在τ²-bench上，遇到要求详细解释才批准更优方案的用户时跌幅更大。仅靠一句提醒注意XY问题的系统指令只能部分缓解，轨迹分析显示当前智能体在识别用户误导与清楚沟通真实问题两方面都明显欠缺。

- 评分 7 · cs.CL
- https://arxiv.org/abs/2609.23935 ｜ https://arxiv.org/pdf/2609.23935

- 评分 8 · cs.CL · 精读候选
- https://arxiv.org/abs/2609.23916 ｜ https://arxiv.org/pdf/2609.23916

### 代理总成本:多智能体 LLM 工作流中记忆注入成本的精确归因
- Total Cost of Agency: Exact Attribution of Memory Injection Cost in Multi-Agent LLM Workflows
- 评分 7 · cs.AI
- https://arxiv.org/abs/2609.23790 ｜ https://arxiv.org/pdf/2609.23790

多智能体 LLM 工作流中每个节点都会把记忆检索结果注入 prompt，这些 token 按输入价格计费，但现有可观测工具只报总成本，分不清节点生成的与被动接收的 token。为此提出 Total Cost of Agency(TCA)，把成本分解为基础 prompt、推理、记忆注入、未命中惩罚与上下文累积五项，并用两遍非计费 token 计数直接测量注入量。在真实 API 的 200 任务企业级 benchmark 上，记忆注入占可变成本 13.6%、全账单约 12%，占比由 1 层的 0 升至 6 层的 27.6%，注入 token 随深度线性增长(R²=0.9974);检索窗口由 32 条降至 2 条可减少 28.7% 注入 token，准确率变化在种子级波动内。

### 如何对 LLM 评委做统计并信任结果：面向小样本 AI 评估的校准推断与 evalstats
- How to Run Statistics over LLM Judges and Trust the Results: Calibrated Inference for Small-Sample AI Evaluation with evalstats

- https://arxiv.org/abs/2609.35815 ｜ https://arxiv.org/pdf/2609.35815
