### 解耦量化:为 LLM Prefill 与 Decode 分别专门化
- Disaggregated Quantization: Specializing LLM Prefill and Decode
- 评分 8 · ▲ 63 · 精读候选
- https://arxiv.org/abs/2609.26333 ｜ https://arxiv.org/pdf/2609.26333

Prefill 与 decode 对量化的需求不同:低精度算术加速提示处理，紧凑权重则缓解生成阶段的显存带宽压力。解耦量化(DQ)由此为两个阶段分别定制计算格式、权重与存储位置:仅在 decode 侧取消激活量化即可在不增加推理开销下提升解码密集任务精度，单独训练 compute-native 的 prefill 权重则加速提示处理，并在 2–3 bit 解码下精度持平或更优。基于已发布的 Qwen3.8-27B GGUF decoder 训练 NVFP4 prefiller，不改动解码 checkpoint 即可把 1-bit 精度在 MMLU-Pro 上提升 32.5 分、MMMU-Pro 上提升 35.3 分。为在单卡容纳额外 checkpoint,offloaded disaggregated prefill(ODP)从 SSD 流式加载权重并按 prompt 长度摊薄开销，8K prompt 下较 weight-only 基线取得 1.78x TTFT 加速，并在 vLLM 及最高 2.8T 参数模型上验证了共享权重的格式解耦。

### RayOrch:面向基础模型数据准备的受血缘控制多粒度数据流编程与执行
- RayOrch: Programming and Executing Lineage-Controlled Multi-Grain Dataflows for Foundation-Model Data Preparation
- 评分 5 · ▲ 47
- https://arxiv.org/abs/2609.18703 ｜ https://arxiv.org/pdf/2609.18703

### 对数线性复杂度的块稀疏注意力
- Block Sparse Attention with Log-Linear Complexity
- 评分 8 · ▲ 21 · 精读候选
- https://arxiv.org/abs/2609.31093 ｜ https://arxiv.org/pdf/2609.31093

长上下文自注意力的二次开销限制了语言模型扩展，块稀疏注意力是高效替代方案，但筛选保留哪些块本身仍需要对所有 query-block 对打分，复杂度依旧是二次的。PISA 采用金字塔式 Top-K 选择:对键做 pooling 构建由粗到细的 O(log N) 层层级，从最粗层开始，每层在受限候选集上用 LogSumExp 打分并选出进入下一细层的候选，整体复杂度降为 O(N log N)。配套实现了面向训练与推理的 Triton 内核，融合层级路由与 LogSumExp 打分，不物化 query-key 分数矩阵。在语言建模任务上，常识推理基准与基线相当，检索类任务结果更优。

### SLCA-GRPO：解决工具调用 RL 中的跨段信用误归因
- SLCA-GRPO: Resolving Cross-Segment Credit Misattribution in Tool-Calling RL
- 评分 8 · ▲ 7 · 精读候选
- https://arxiv.org/abs/2609.29050 ｜ https://arxiv.org/pdf/2609.29050

工具调用智能体的输出混合了结构化工具调用与自然语言总结，GRPO 这类同策略 RL 会把轨迹级标量优势广播给所有 token，使总结生成的梯度噪声污染工具决策 token，造成跨段信用误归因。SLCA-GRPO 以 Segment-Locked Credit Assignment 在单组 rollout 内按结构分段解耦优势估计，无需从中间状态额外采样，并用 Schema-Guided LLM Simulator 提供可扩展的模拟环境、用 Hierarchical Rewards 把执行优势路由给工具 token、偏好优势路由给总结 token。在 7B 模型、同等训练预算下，其同域评测比 GRPO、ToolPO、RLTR 高 2.53pp，BFCL 高 1.36pp，τ²-Bench 高 9.15pp，同时减少工具冗余与调用成本。
