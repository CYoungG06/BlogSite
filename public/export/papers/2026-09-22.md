- 评分 7 · ▲ 29
- https://arxiv.org/abs/2609.24983 ｜ https://arxiv.org/pdf/2609.24983

针对对齐数据与 Agent 轨迹标注成本高的问题，onPanda 以 Token 级修正为核心交互:标注者定位第一个不合适的 Token，从模型候选 Token 中选择替换或自由改写，系统截断其后内容并从修正后的前缀继续生成，循环「定位—修正—续写」直至满意。由于最终回复中绝大多数 Token 仍由模型自身采样产出，数据保留了模型的采样分布，适合构建 on-policy 的 SFT 与偏好数据;标注过程中记录的 Token 级修正还天然提供了带精确位置的正负样本对。小规模对照研究显示其中位标注时间比人工后编辑减少 52%，工具亦可连接外部工具与 harness，在真实环境中交互式标注轨迹，并同步开源数据集 Panda-CVL 与 Token 级修正 benchmark。

### 1% 的 Token 就够了:论 On-Policy 蒸馏中的梯度估计
- 1% of Tokens Can Be Enough: On Gradient Estimation in On-Policy Distillation
- 评分 8 · ▲ 11 · 精读候选
- https://arxiv.org/abs/2609.24432 ｜ https://arxiv.org/pdf/2609.24432

稀疏 on-policy 蒸馏只在学生轨迹的一小部分 token 上施加教师监督，但从采样出的下一个 token 估计梯度会引入噪声，使本来有用的教师信号产生不可靠更新。该工作在固定前缀下用信息几何分析这一估计问题，基于信噪比分解提出信息效率比(IER)，刻画最优标量基线下的相对梯度估计误差，并通过候选集近似把 IER 与已有有用性分数结合来做 token 选择，同时保留采样的 reverse-KL 训练目标。在数学与医学推理任务上，加入 IER 在多种设置下改进现有选择器，0.1%–1% 的极小 token 预算即可追平甚至超过不做 token 选择的完整 OPD。这说明稀疏监督分配需要同时考虑教师信号的有用性与梯度估计的可靠性。

### The Functionalizer:面向子词分词的无损功能分解
- The Functionalizer: Lossless Functional Decomposition for Subword Tokenization
- 评分 7 · ▲ 6
- https://arxiv.org/abs/2609.15991 ｜ https://arxiv.org/pdf/2609.15991

标准子词分词器要么把同一单词的不同拼写变体(hello、Hello、HELLO、Héllo)当作互不相关的词表项，使嵌入空间碎片化，要么用有损归一化直接丢弃这些变化。Functionalizer 作为无损预分词框架，在分词前把正字法与结构变化分解为「操作码/操作数」前缀流:规范基词作操作数，参数化变换算子作操作码并编码于 Unicode 私用区，算子覆盖大小写(CAPITALIZE)、变音符(13 个专用 opcode)与字符重复(REPEAT、MULTIREPEAT)，且完全可逆。在自然语言与代码语料上，该方法在无约束穷举条件下实现完整语料覆盖的同时显著缩小词表，实际词表槽位需求最多降低 19.7%;98M 参数 GPT-2 的下游评测显示 Python 代码语法有效率由 7.70% 升至 9.12%，并减少自然语言中的重复 n-gram。结果表明功能分解可成为词表高效、结构感知的语言建模机制，但生产规模的有效性仍待验证。

### 面向大语言模型的全流程 FP8 强化学习

### 语言模型的测谎测试:读取模型不愿透露的知识

- 评分 8 · ▲ 4
- https://arxiv.org/abs/2609.21996 ｜ https://arxiv.org/pdf/2609.21996

大模型可能明知答案却故意不报(如评估中的 sandbagging)，仅凭输出无法区分「隐瞒」与「不会」。受司法测谎中隐藏信息测试的启发，Probe of Internal Recognition(PIR)把问题连同候选答案一并输入，从模型内部状态读出它认出哪个候选，无需参照模型或标注语料。在 Gemma、Qwen、Llama、Mistral、Phi 五个家族的八个模型上，PIR 以 0.70–0.87 的平衡准确率还原被识别答案，高于未知项基线 0.28–0.40 与随机 0.25;面对提示欺骗、训练出的 sandbagging、密码锁与电路破坏检查点等隐瞒形式仍有 0.85–0.93，而当遗忘真正抹去知识时识别率降到未知问题水平。据此可区分「不愿答」与「无法答」，用于 sandbagging 审计与遗忘验证。
