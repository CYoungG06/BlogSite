### DeepSeek-V4.1-Flash:把 KV Cache 压缩推向极限
- DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression
- 评分 10 · ▲ 67 · 精读候选
- https://arxiv.org/abs/2609.19969 ｜ https://arxiv.org/pdf/2609.19969

长时程 Agent 带来输入密集负载，prefill 算力与 KV cache 对 HBM、SSD 容量和带宽的占用成为降低部署成本的主要瓶颈。DeepSeek-V4.1-Flash 是支持百万 token 上下文的多模态 MoE 模型，552B 总参，采用 Causal Encoder-Decoder 架构，解码激活 16B、prefill 仅激活 8B;通过 Compressed Sparse Attention 2 的跨层 KV 复用与 FP4 KV 缓存，把常驻 HBM 的全局 KV 压到 890 字节/token，约为 DeepSeek-V4-Flash 的 1/4，并借 SWA Bounded Replay 把持久化 KV 降到约 1/8，性能反而优于基线。模型在 45T token 多模态语料上预训练并完成完整后训练，在文本与多模态 Agent 场景表现强劲。

### 当 EOS Token 不一致时:理解在线策略蒸馏中的长度膨胀

- 评分 8 · ▲ 56 · 精读候选
- https://arxiv.org/abs/2609.20511 ｜ https://arxiv.org/pdf/2609.20511

在线策略蒸馏(OPD)中，学生回答常过度变长甚至耗尽生成长度预算，一个重要来源是基座学生与后训练教师的终止 token 不匹配:即使声明的停止集合相同，停止概率也落在不同 EOS token 上，从而压制学生偏好的终止动作、又无法可靠迁移教师偏好的动作。仅对齐解码停止集合不够，把功能等价的 EOS 视为同一语义停止动作，可在 Qwen3、Llama、Gemma 上显著缓解长度膨胀。按 K2-Horizon 阶段的训练分析显示终止偏好会明显漂移，且 OPD 后期存在与终止对齐无关的独立长度膨胀。

同策略自蒸馏(OPSD)让学生模型从一份能看到答案或解题过程的冻结自身副本中学习，但这份额外信息相对蒸馏本身究竟贡献多少仍不清楚。作者构建 AMPLE-Math，包含 5319 道数学题与六种共享同一答案的推理视角，并将各视角与匹配的无参考蒸馏逐一对比。在 Qwen3-1.7B 上，无参考蒸馏已解释了思考模式下领域内与外部基准的大部分提升，参考信息的额外收益有限，仅在精修解答上最强;SmolLM3-3B 在第 50 步时完整推理轨迹带来 2 个百分点增益，而这些收益依赖学生端被训练。相同 checkpoint 下把短直接回答 rollout 换成思考 rollout，会让两族模型的收益转为损失。结果提示 OPSD 主要靠直接回答与思考推理共享的参数改善对既有推理能力的调用，特权参考的价值在于跨模式迁移的增益而非揭示答案的多少。

### 复值相位相干 Transformer

- 评分 8 · cs.LG
- https://arxiv.org/abs/2609.22415 ｜ https://arxiv.org/pdf/2609.22415

### 可用护栏:跨 ML 系统认证选择性预测
- Available Guardrails: Certifying Selective Prediction across ML Systems

### 面向LLM Agent的可解释记忆决策控制器：基于三信号互补，解耦置信度与一致性
