### 用同策略反向蒸馏激发弱到强泛化
- Eliciting Weak-to-Strong Generalization with On-Policy Reverse Distillation
- 评分 8 · ▲ 84 · 精读候选
- https://arxiv.org/abs/2609.08798 ｜ https://arxiv.org/pdf/2609.08798

弱到强泛化关注更强的学生能否从弱监督者身上学到超越教师的能力，这直接关系到模型代际迭代与多领域能力整合的成本。常规蒸馏把弱教师当作优化目标，会把教师的能力上限强加给学生。为此提出 On-Policy Reverse Distillation（OPRD）：在学生 rollout 上度量教师策略相对参考策略的偏移，沿该方向放大由 verifier 驱动的学生策略梯度，且只重标定 verifier 支持的更新，故策略优化的稳定点不变而收敛更快。在代际迁移与多教师蒸馏中，OPRD 以更少的学生更新取得更高性能，学生行为也更接近纯 verifier RL 模型而非弱教师。

### BeaconKV：由 Beacon 查询引导的键值缓存压缩，面向高效大型推理模型推理
- BeaconKV: Key-Value Cache Compression Guided by Beacon Queries for Efficient Large Reasoning Model Inference
- 评分 8 · ▲ 32 · 精读候选
- https://arxiv.org/abs/2609.04971 ｜ https://arxiv.org/pdf/2609.04971

长思维链推理使 KV cache 随序列长度线性膨胀，长推理轨迹常直接超出 GPU 显存。现有压缩方法用近期 query 估计未来 token 重要性，但分析表明该假设在长程推理中失效：某些解码步会产生 Thought Revisiting Token，重新关注轨迹早期制定的解题计划，而这些 query 在嵌入空间中聚成少量相似簇。BeaconKV 无需训练，为每个全局 query 簇保留一个 beacon query 作为紧凑代表，据此预判哪些 KV 会被重新访问，而无需存储完整 query 历史。在四个开源 LRM 与多个推理基准上，内存最多降低 5.8 倍、吞吐提升 4.3 倍以上，精度接近全量 cache。

### CoVeR:面向 VLM 多视图 3D 推理的基于覆盖率的 token 剪枝

- 评分 7 · ▲ 20
- https://arxiv.org/abs/2609.08345 ｜ https://arxiv.org/pdf/2609.08345

### CompassOPD:通过族内似然偏移实现跨族在线策略蒸馏

- 评分 8 · cs.LG
- https://arxiv.org/abs/2609.10154 ｜ https://arxiv.org/pdf/2609.10154
