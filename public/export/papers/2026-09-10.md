### 通过世界模型扩展自动研究智能体
- Scaling Automatic Research Agents via World Models
- 评分 9 · ▲ 433 · 精读候选
- https://arxiv.org/abs/2608.12564 ｜ https://arxiv.org/pdf/2608.12564

自动科研(AutoResearch)智能体的 RL 后训练中，轨迹生成可通过批处理共享算力，而每次环境执行都独占沙箱与真实机器时间，后者随轨迹变长成为训练瓶颈。所提 World Model RL(WMRL)用世界模型替代真实环境执行，并针对其奖励的偏差与噪声分别引入 Online Debiasing 与 Inverse-Variance Denoising，理论上证明二者严格改善收敛性。实验在不同任务与智能体规模上取得 3–4 倍训练加速且超越标准 RL 基线，后训练得到的 4B/9B 智能体在留出基准上胜过 48B 与 120B 的开源权重智能体，方法还可迁移到具身 VLA 策略后训练。

### AgentGrad：干预引导的多智能体系统提示优化
- AgentGrad: Intervention-guided Prompt Optimization for Multi Agent Systems
- 评分 7 · ▲ 89
- https://arxiv.org/abs/2609.08572 ｜ https://arxiv.org/pdf/2609.08572

多智能体系统的性能高度依赖各 agent 的提示设计，现有文本梯度方法存在两处缺陷：提取梯度时未验证修改目标提示是否真能解决失败，也缺少对目标 agent 中间输出的 agent 级监督；聚合时随机分组拼接易混入无关失败模式，导致提示泛化差。AgentGrad 用顺序干预逐次改动单个 agent 的行为，定位真正能消除失败的目标 agent，并以该 agent 修改后的输出作为细粒度监督，再对语义相近的梯度聚类、抽象为可泛化的纠正模式。在五个多智能体基准上取得 SOTA，平均墙钟优化时间比次快基线缩短 2.5 倍。
