### HarnessDev：LLM 能否创建并进化自己的 Agent Harness？
- HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?
- 评分 8 · ▲ 230 · 精读候选
- https://arxiv.org/abs/2609.01437 ｜ https://arxiv.org/pdf/2609.01437

Agent 从原型走向部署时，性能越来越依赖模型外部的执行基础设施（即 agent harness），而现有评测只报告固定 harness 下的任务表现，忽略了模型自身开发 harness 的能力。HarnessDev 将评测单元从任务输出转向可运行的执行系统，分为 Creation 与 Evolution 两阶段：前者从种子代码和少量用例构建完整执行系统，后者基于下游执行反馈迭代修订自身创建的 harness。评测覆盖 6 个创作者 LLM、4 个领域、5 个下游 benchmark 共 2,207 个实例，结果显示生成 harness 在代码与搜索研究任务上仍落后于人工参考，在写作与机器学习实验上相当或超越，但执行成本差异大；进化带来部分不稳定收益且难以跨模型迁移。该 benchmark 为 Agent 基础设施自动化评估提供了新视角。

### EarlyEval:通过早期结果预测实现更廉价的智能体评估
- EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction
- 评分 7 · ▲ 112
- https://arxiv.org/abs/2609.02783 ｜ https://arxiv.org/pdf/2609.02783

评估 LLM 智能体代价高昂，前沿模型在智能体基准上单次运行即可花费数百至数千美元，且迭代开发中需反复付费。已有工作聚焦基准蒸馏以减少任务数，却未降低单个任务的执行开销。EarlyEval 提出早期结果预测，从任务内部削减成本:核心洞察是智能体的最终结果往往在执行完成前就能从其中间行为中显现。框架训练一对 LightGBM 成功/失败分类器，基于行为、文本与参考解特征，当任一分类器越过校准置信阈值即提前终止运行，每步开销可忽略。在 SWE-bench Verified、TerminalBench 与 Toolathlon 三个基准上，EarlyEval 可消除 13%-26% 的智能体步骤，最多节省 44.1% 输入 token 与 29.4% 输出 token，预测准确率达 89%-97%，而每个智能体的解决率平均仅受 1-2 个百分点扰动。该方法为智能体评测成本控制提供了轻量且通用的新维度。

### 语言模型能控制自身注意力
- Language Models Can Control Their Own Attention
- 评分 8 · ▲ 56 · 精读候选
- https://arxiv.org/abs/2609.02737 ｜ https://arxiv.org/pdf/2609.02737

Transformer 解码时虽只关注少量上下文，却仍需读取完整 KV cache 来定位关键 token，而现有基于代理分数的预选方案仍是每步 O(N)。Declarative Attention 让模型在思维链中主动声明注意力模式:<global> 读全量、<focus> 读指定区间、<local> 只读最近输出;推理引擎像解析工具调用一样处理声明，从而跳过大部分 KV 读取。在 15 项长上下文任务的零样本评测中，该方法使 Gemma-4-31B 和 Qwen-3.6-27B 的解码期总注意力 token 数分别下降 52.0% 与 31.1%，准确率损失仅 1.27pp 与 2.75pp，且损失随模型规模缩小。该协议开辟了稀疏注意力的新维度，后续结合训练方法仍有提升空间。
