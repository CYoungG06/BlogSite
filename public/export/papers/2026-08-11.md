### 无监督的On-Policy自蒸馏
- On-Policy Self-Distillation without Any Supervision
- 评分 8 · ▲ 105 · 精读候选
- https://arxiv.org/abs/2608.06296 ｜ https://arxiv.org/pdf/2608.06296

现有的on-policy自蒸馏方法仍依赖外部监督信号（如真值标签、环境反馈或大模型指导），难以称为真正的自蒸馏。U-OPSD仅利用模型自身采样多次生成，通过自一致性阈值下的多数投票构造伪解，并只在模型自信但错误的样本上对模型分布进行条件化自蒸馏，实现无需任何监督的自校正。在AIME24、AIME25、HMMT25、MATH500和AMC23五个数学推理基准上，U-OPSD在Qwen3非思考模式下较基础模型平均提升8.5%（4B）和10.7%（8B），分别超过有监督的OPSD 3.2%和2.3%；思考模式下与OPSD持平或略优，并超越GRPO约1%。该方法为后训练提供了一种利用模型内部一致性的无监督自蒸馏范式，适用于推理能力自我提升场景。

### 智能体记忆蒸馏：利用层级教师记忆赋能小型 LLM 智能体

### OasisKV:通过前瞻稀疏预取将解码中 KV Cache 扩展到 HBM 之外
- OasisKV: Scaling In-Decode KV Cache Beyond HBM with Lookahead Sparse Prefetching
- 评分 8 · ▲ 21 · 精读候选
- https://arxiv.org/abs/2608.08097 ｜ https://arxiv.org/pdf/2608.08097

LLM 推理服务日益受内存而非算力限制，长上下文与长思维链场景下 KV cache 占据主要内存占用与流量，HBM 容量成为吞吐瓶颈。OasisKV 在解码阶段将完整 KV cache 与 HBM 解耦，利用解码注意力的天然稀疏性，仅在 HBM 中保留最相关 token 的 KV 条目;并基于投机解码起草的前瞻 token 提前准确预测未来重要 KV 块，通过后台注意力流水线从高容量内存(主机或远端)预取并暂存到 HBM，供下一步解码使用。基于 vLLM 的实现表明，在 2048 token 的 KV 预算下精度仅比全注意力低 0.7 个点;推理工作负载吞吐量达密集 vLLM 的 1.69 倍(精度损失 0.1)，多 GPU 长上下文服务最高 2.1 倍;在 prefill-decode 分离下吞吐约 2 倍，同时每请求 KV 传输量减少 6.5–9.7 倍，decode 节点宿主内存占用降低 2.2–2.6 倍。该工作为内存受限的长上下文与长推理场景提供了一套面向内存的推理系统设计范式。

### Evidence-RL：迈向证据密集的视觉推理
- Evidence-RL: Towards Evidence-intensive Visual Reasoning
- 评分 8 · ▲ 13 · 精读候选
- https://arxiv.org/abs/2608.08021 ｜ https://arxiv.org/pdf/2608.08021

视觉语言模型应依据图像中的具体证据作答，而非依赖语言先验或数据捷径。现有感知类后训练方法通过全局扰动或注意力代理鼓励用图，却未检验答案是否因果地依赖支撑它的局部证据。提出反事实证据解缠（Counterfactual Evidence Disentanglement, CED）：对每个回答中和目标物证据区域，并与匹配的非证据区域比较支持度下降，再将该信号与答案正确性一同纳入 GRPO，奖励走证据路径的正确回答。CED 仅需弱物体级提议，无需问题级证据标注，且不增加推理开销；在 9 个公开基准和 4 个骨干上超越已有 RL 后训练方法。

### RoMeRL：通过降阶效用状态平衡自进化智能体记忆中的反馈覆盖与记忆-奖励陷阱
- RoMeRL: Balancing Feedback Coverage and the Memory-Reward Trap in Self-Evolving Agent Memory via Reduced-Order Utility States

- https://arxiv.org/abs/2608.09043 ｜ https://arxiv.org/pdf/2608.09043
